# 微信消息平台

通过安卓手机上的 AutoJs6 读取和发送微信消息，在电脑网页中管理会话和 AI 回复。

```
电脑网页 ──► wechat-web（Go，127.0.0.1:8787）──HTTP──► wechat-bridge（手机 AutoJs6，:8766）──► 微信界面
                   ▲                                        │
                   └──────── 长轮询消息事件 ◄────────────────┘
```

| 目录 | 内容 |
| --- | --- |
| [`wechat-bridge/`](wechat-bridge/README.md) | 手机脚本：HTTP 接口 + 微信界面操作，部署脚本 |
| [`wechat-web/`](wechat-web/README.md) | Go 服务：会话存储、任务调度、AI 回复、内嵌网页 |
| `*/.state/` | 本地配置、凭证、消息和图片，不要分享 |

## 启动

1. 手机安装 AutoJs6，开启无障碍、通知使用权和随选朗读（当前微信需要它暴露控件）。
2. 手机 USB 连接电脑，按 [手机部署说明](wechat-bridge/README.md) 部署。
3. 在 `wechat-web/` 执行 `./run.sh`，打开 http://127.0.0.1:8787 ，在“手机连接”中添加手机 IP 和 Token。可以添加多台手机，每台登录一个微信账号。

日常通信走局域网，ADB 只用于部署和排查。

## 限制

- 微信界面没有消息编号，消息按屏幕内容顺序比对后增量记录；无法衔接时会标记“可能有遗漏或重复”。
- 发送确认表示手机界面上观察到了新消息，不表示对方已收到或已读。结果未知的发送不会自动重发。
- 收到的图片默认点开大图取原图（会话设置里可改为只要缩略图）；缩略图只有手机屏幕上显示的大小。表情包只有聊天页面的截图。图片发送依赖微信分享界面，需在当前手机上实际验证。
- 群聊的发送人名称来自头像控件的描述（“xxx头像”），头像是聊天页面的截图。
- 公众号（“订阅号消息”）不读取也不显示。
- 消息转发只转发服务运行期间读到的新来信，靠手机逐条发送，发送确认同样只表示手机界面上看到了消息。详见 [转发说明](wechat-web/README.md#消息转发)。
- 会话设置里可以删除电脑上的聊天记录，手机微信里的聊天不受影响；之后读到的旧消息不会被重新导入。
- 手机桥启动后会在微信“我”页面读取当前登录的微信号（用户可见的微信号，不是 wxid）。会话按微信号分开保存，网页左上角切换账号；任务交给当前登录着该账号的手机，手机核对微信号不一致时拒绝执行。
