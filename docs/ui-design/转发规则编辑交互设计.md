# 转发规则编辑交互设计

转发规则在一个紧凑面板内完成编辑。来源和目标支持就地搜索多选，勾选即时写入规则草稿；设备策略默认收成一行，关键词直接填写，最后由“保存规则”统一生效。取消独立选择页、“应用选择”、关键词模式切换和常驻预览栏。

本版为设计及本地交互演示，未修改生产页面或后端。演示不连接手机、不发送消息，保存仅保存在当前页面内存中，刷新页面恢复演示初始值。此前规则编辑设计与本版冲突时，以本版为准；上一版保存在 [历史交互说明](转发规则编辑交互设计-v3.md)。

## 布局与视觉

桌面编辑面板由 820px 收窄到 640px，保留列表上下文；窄屏切换为整屏编辑。标题和底部操作固定，正文独立滚动，关闭入口始终可见。正文 14px、会话名 13px、辅助信息 11–12px、标题 18px；控件约 34px，分组间距约 20px。保持现有绿色主题，深色模式统一背景、文本、边线、选中态和警告颜色。

规则名称与启用状态在顶端，随后是来源、目标、条件、更多条件与消息格式。启用开关明确随规则保存，不即时作用于设备。底部一行摘要展示来源数量、目标数量、包含关键词和消息类型，不重复展示已在目标行解释的异常。

## 来源和目标就地选择

点击“选择会话”，在当前分组下方展开搜索、微信号筛选和按账号分组的会话列表；不进入新页面，不叠加弹窗。一次只展开一个选择区或设备选择区，避免连续浮层遮挡。

勾选或取消立即修改规则草稿。搜索、账号筛选、收起和 Esc 均不清除选择，不额外点击“应用”或“完成”。关闭搜索区后，已选会话列表直接反映结果。唯一向服务端提交的动作是底部“保存规则”。

搜索同时匹配会话名、账号名和微信号，账号筛选只控制可见候选。跨账号同名会话保留账号归属，避免误选。候选行点击整行可切换勾选；键盘可用 Tab、空格选择，Esc 收起并返回触发按钮。

已选项以会话名为主，账号名称、微信号和类型作为次要信息。前三项直接展示，超过三项显示“另有 N 个，展开查看”，展开后可查看和删除全部已选项；不能只显示数量却无法管理被筛选隐藏的选择。移除不需要确认，只有最终保存才生效。

来源与目标必须互斥，候选列表就地禁选并显示“已是来源”或“已是目标”；目标类型未识别时显示“请先设置会话类型”。旧规则中的已删除、换号或失效会话保留原项并提示原因，不自动删除。移除目标同时删除该目标设备策略，重新加入默认自动选择。

## 设备策略和运行状态

每个目标下方默认只显示“执行设备 自动选择 · N 台可用”或“执行设备 设备名 · 状态”。点击这一行展开同账号设备选项；选择后立即更新草稿并收起。默认不放常驻下拉框。

自动选择仅在目标账号下调度设备。指定设备的状态按实际选中的设备计算，即使该账号还有其他可用手机，也不能将指定策略标成可执行。设备离线、未就绪、换号、移除及缺少权限，需要显示具体原因和对这个目标的影响。

指定设备不可用时，不自动切到另一台手机；该目标行持续提示“此目标将跳过”。临时离线允许保存有效配置。设备已不属于目标账号属于配置错误，必须重新选择；状态变化不覆盖用户的草稿。其他目标仍逐项判断是否可执行，不能用整体“已连接”代替。

来源设备状态与目标设备状态分开处理。来源无法读取时显示原因；未开定时读取时说明“仅在读到新消息后转发”，不自动开启读取、不暗示保存规则就会开始收消息。

## 条件和消息格式

包含关键词直接使用标签输入，没有额外模式切换。输入后按回车、逗号或换行添加；失焦或保存时提交尚未添加的文字，避免漏掉最后一个词。移除空白和重复词；清空全部标签即表示不限制包含关键词。中文输入法选词中的回车不触发添加。

| 字段 | 含义和交互 |
|---|---|
| 包含任一关键词 | 多个词任一命中；留空不限，其他条件仍生效 |
| 排除任一关键词 | 放在更多条件；命中任一词就排除，即使同时命中包含词 |
| 发送人 | 按完整群昵称匹配，多个昵称任一满足；纯联系人来源不引导填写群昵称 |
| 正则 | 与其他文字条件同时满足；使用 Go RE2 语义，保存时由后端权威校验 |
| 同时转发图片 | 开启后在开关旁常驻“图片不检查关键词和正则，仅按发送人过滤” |
| 相同文字去重 | 新规则默认 30 分钟，0 关闭，范围 0–1440；同规则跨来源按原文去重，图片不去重 |
| 文字格式 | 默认原文；选择自定义才显示编辑器与示例预览。必须含 {text}，最多 200 字，支持 {sender} 和 {chat} |

不同条件之间为“同时满足”，单个名单或包含词内部为“任意满足”。更多条件默认折叠，但折叠标题显示已配置的排除词、发送人、正则、格式与去重摘要，避免隐藏条件导致误判。

底部只展示转发关系的短摘要，完整摘要可在悬停和辅助阅读中获取。仅编辑自定义格式时显示示例预览，并标注“不发送消息”；它不是实际匹配测试。

规则处理之后读取到的新来信，不重放旧记录。多个来源的匹配来信分别发往所有目标，不是来源与目标一一配对。同规则只要至少一个目标成功入队，相同文字就进入去重窗口；离线目标恢复后不会自动补发当时跳过的消息。

## 编辑和关闭状态

规则草稿是唯一待保存状态，不再创建选择子视图的临时草稿。打开已有规则无改动时显示“已保存”并禁用保存；修改后显示“未保存的修改”；改回原值恢复已保存状态。设备状态刷新、搜索、筛选、展开、主题切换不属于配置修改。

| 动作 | 处理 |
|---|---|
| 点击选择区外的面板内容 | 收起选择区，保留刚才的选择，继续编辑 |
| 点击面板外部、关闭或取消 | 收起子区并尝试关闭规则；无修改直接关闭，有修改询问是否放弃 |
| Esc | 优先收起当前会话或设备选择区，保留选择并恢复焦点；没有展开子区时再尝试关闭规则 |
| 放弃确认 | “继续编辑”保留草稿；“放弃修改”恢复上次保存值并关闭 |
| 规则编辑启用开关 | 更新草稿，保存后生效 |
| 规则列表启停 | 保留即时独立提交；提交中禁用，失败回滚并显示原因 |

选择区不是模态浮层，点击其他字段会直接进入该字段，不要求先手动关闭。关闭规则的确认只保护未保存修改；正常保存不增加确认步骤。

## 保存和校验

保存前检查至少一个来源和目标、双方互斥、会话有效、名称最多 40 字、关键词名单限制、去重范围、正则和消息格式。错误位于对应字段附近，自动展开必要区块、滚动到首个错误并聚焦；已有输入完整保留。

关键词留空合法，不再出现“包含关键词但无关键词”的模式错误。结构错误阻止保存；设备暂时离线等运行问题以目标行警告提示，允许保存。后端再次校验会话、账号和设备归属，不依赖前端禁选。

提交期间按钮显示“保存中”，禁止重复提交和关闭，表单停止接受修改。失败保留草稿、滚动位置和选择，显示明确原因；成功更新该条规则并关闭面板，显示轻量反馈。真实接口失败不能被演示成功反馈替代。

## 交互演示和实施范围

演示可操作来源和目标搜索、多选、冲突禁选、跨账号筛选、已选折叠与移除、逐目标设备选择、关键词添加和删除、图片说明、启停草稿、更多条件、自定义格式预览、未保存关闭确认及内存保存。源码独立位于设计目录，不影响当前业务前端。

演示简化了设备列表和状态，仅模拟指定设备离线；不模拟服务端失败、设备换号和 Go RE2 正则校验。这些情况按本文规范在实施阶段接入实际接口。不能用 JavaScript 正则校验替代 Go RE2。

现有来源、目标、逐目标设备策略、过滤条件、图片、格式及去重字段均可复用。本版不增加自动补发、真实发送测试或新的读取策略。

验收重点为：筛选不清除已选，收起不撤销选择，来源目标互斥，移除目标清理设备策略，指定设备不可用不自动换机，空关键词合法，输入框剩余关键词在保存时加入，关闭保护草稿，改回原值不误报修改，以及深色与窄屏下关闭和保存入口可见。
