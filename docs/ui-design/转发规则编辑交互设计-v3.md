# 转发规则编辑交互设计

规则编辑采用较宽的单页面板，将来源、目标及各目标的执行设备直接展示，条件按使用频率分组，右侧实时预览转发关系。保留现有每条规则独立保存的方式，适配多微信号和多设备。

本版为设计方案与演示稿，未修改生产页面或后端。演示数据不连接手机；示例文字用于格式预览，不做真实发送。此前转发规则编辑相关设计与本版冲突时，以本版为准。

## 界面与视觉

桌面面板宽 820px，标题和底部操作固定，正文独立滚动。正文以配置区和 218px 预览区并排展示；手机改为整屏编辑，预览置于配置下方。正文 14px、会话名 13px、辅助信息 11–12px、面板标题 18px；控件高约 34px，区块间距 20px。延续当前导航和绿色主色，不放大字体及留白。

来源、目标、条件依次排列。规则名称和启用状态放在最上方；目标会话的执行设备就在该会话下方。更多条件默认折叠，标题保留已配置条件摘要，防止隐藏配置被忽略。所有背景、文本、边框、悬停及选中态跟随主题，深色模式不出现白底选择器。

## 来源与目标选择

已选会话以紧凑列表展示，会话名为主信息，下一行显示账号名称、微信号和会话类型。来源支持多个账号、多会话；目标同样支持多个账号、多会话。会话按唯一编号绑定，不按显示名称识别。

点击“编辑来源”或“编辑目标”，在同一个面板内进入选择视图；不叠加第二层浮窗。选择视图包含搜索、微信号筛选、按账号分组的会话列表和已选区。无需先指定设备才能选择会话。筛选和搜索只改变可见列表，不清除其他账号下的选择；无匹配结果显示就地空态。

选择视图保留一份临时草稿。“应用选择”仅写回规则草稿并返回编辑；“返回”、关闭或 Esc 放弃本次选择，恢复进入选择视图前的值。唯一向服务端提交的按钮是规则编辑底部“保存规则”。窄屏用选择数量与可展开已选列表替代常驻已选侧栏，仍能查看和移除被筛选隐藏的选择。

目标列表中，已作为来源的会话禁选，并显示“已是来源”；类型未识别的会话禁选，显示“请先设置会话类型”。来源选择也禁选已有目标，避免双向操作产生冲突。既有无效配置不自动删除：保留原项并显示原因，交由用户调整。移除目标同时移除该目标设备策略。

## 多设备策略与可用性

每个目标都有独立设备策略。默认“自动选择”，只在该目标账号下选择设备，并显示当前可用设备数。指定设备列表仅列出同账号设备，名称后标明可用、忙碌、离线或未就绪；较长原因通过行内提示展开。

自动策略有可用设备并不等于指定策略可执行。状态必须根据该目标当前实际选择的设备计算，不能仅统计账号内是否存在任意可用设备。来源的读取状态与目标的发送状态分别呈现，不能用目标可用推断来源正在收消息。

指定设备离线、换号、移除或缺少权限时，在目标行显示具体原因。离线可暂存配置，不自动改为其他手机；提示“指定设备不可用，此目标将跳过”。若设备身份不属于目标账号，要求重新选择后才能保存。其他目标是否可执行逐项显示，不以整体“已连接”掩盖局部问题。

来源账号没有可读取设备时提示具体原因；能读取但未配置定时读取时说明“仅在读到新消息后转发”，不暗示自动启动读取。规则编辑不代用户改动来源会话的读取策略。

## 条件与实际转发含义

| 配置 | 交互与语义 |
|---|---|
| 文字匹配 | “不限关键词”或“包含关键词”；切换只控制关键词条件，其他已配置条件仍有效并显示摘要 |
| 包含关键词 | 标签输入，回车、逗号或换行添加；去除空白和重复词。任意一个命中即满足此项 |
| 排除关键词 | 更多条件中设置；命中任意一个即排除，优先于包含词的匹配结果 |
| 发送人 | 更多条件中设置；按完整群昵称匹配，多个昵称任一满足；纯联系人来源时不引导配置群昵称 |
| 正则 | 选用后显示输入和错误；需同时满足其他文字条件，使用 Go RE2 语义 |
| 同时转发图片 | 默认按已保存配置展示；开启立即说明“图片不检查关键词和正则，仅按发送人过滤”，不能使用户误以为只转发含关键词的图片 |
| 去重 | 默认新规则 30 分钟；0 表示关闭，范围 0–1440。同规则、跨来源按相同文字去重；图片不去重 |
| 格式 | 默认原文；自定义必须包含 `{text}`，最多 200 字，支持 `{sender}`、`{chat}`；实时展示转发后的示例文字 |

“包含关键词”但没有关键词时，就地提示并阻止保存，避免空列表被解释为不限。“不限关键词”明确保存空包含词列表。不同条件之间按“同时满足”组合；包含词内部、发送人名单内部按“任意满足”组合。图片的规则例外始终显示在开关附近。

规则作用于之后读取到的新来信，不主动重放已有聊天记录。多个来源的匹配来信分别发往所有目标，不做来源与目标一一配对。去重记录为同一条规则共享：只要有目标成功入队，相同文字会进入去重窗口；不能承诺离线目标恢复后自动补发。当前跳过的消息不会由本方案新增补发能力。

## 预览与反馈

右侧仅保留转发关系、条件摘要、逐目标可用性、格式预览及去重说明。常驻预览不加入发送测试或额外确认步骤。示例预览不是实际消息匹配测试，不展示虚假的“已匹配成功”。

规则名称、条件和选择发生变化时实时更新摘要；设备状态自动刷新时只更新可用性，不覆盖输入或已选项。没有设备等运行状态问题显示黄色提示，结构错误和不合法输入显示字段附近的错误。

## 保存与关闭

| 状态或动作 | 处理 |
|---|---|
| 打开已有规则 | 加载原值；无修改时显示“已保存”，保存按钮禁用 |
| 新建规则 | 来源和目标为空，启用默认开启；缺少必要选择时提示具体缺项 |
| 字段校验 | 至少一个来源和目标、双方不重叠、会话有效、名称最多 40 字、正则可编译、格式及去重合法；失败定位首个错误 |
| 运行状态异常 | 展示具体影响，允许保存有效配置；不将离线误报为配置错误 |
| 保存中 | 按钮显示“保存中”，禁用重复提交和关闭，防止提交结果与草稿分离 |
| 保存成功 | 关闭面板，更新该规则列表和状态，显示轻量成功反馈 |
| 保存失败 | 保留全部草稿和滚动位置；错误靠近相关字段，允许重试 |
| 取消、关闭、Esc 或点击外部 | 无修改直接关闭；有修改询问“放弃未保存的修改？”并提供“继续编辑 / 放弃修改” |
| 选择视图关闭 | 先退出当前选择草稿，不同时关闭整条规则；选择视图返回也不提交服务端 |

规则编辑内的启用开关随规则一起保存；规则列表中的启停仍即时保存，失败回滚。两处必须通过“保存后生效”与提交中状态区分，避免修改开关却没有保存。

## 实施范围与验收

前端需调整面板布局、会话选择子视图、标签输入、逐目标设备状态、条件摘要与字段校验。现有 `sources`、`targets`、`target_phones`、过滤条件、图片、格式、去重及单条规则保存接口可复用；本版不引入自动补发、消息匹配测试或新的读取策略。账号与设备归属校验须由后端再次确认，前端提示不能替代提交校验。

验收覆盖跨账号同名群、搜索后选择保留、取消子视图恢复、来源目标冲突、指定设备离线但同账号其他设备可用、设备换号、图片过滤说明、不限关键词切换、无关键词阻止保存、无修改关闭、保存失败草稿保留、窄屏完整滚动以及两套主题。

演示稿中的会话筛选、来源临时选择及应用、主题、设备切换、文字匹配切换和图片提醒可操作；目标应用、关键词标签编辑、保存与关闭确认以说明反馈模拟，不能替代实际功能验收。
