# 子页面 UI 设计稿

2026-10-10 · 设计评审稿 · 不修改业务代码

本文件细化并调整上一版方案。导航、组件、色彩保持统一；涉及冗余交互的部分，以本文件为准。图中数据为演示数据，新增能力仍以原方案的实施范围为准。

后续多设备与多微信号支持见 [多设备与多微信号设计补充](多设备与多微信号设计补充.md)。账号、设备选择及任务归属以该补充为准；现有图稿作为单设备上下文的视觉示例。

## 统一视觉规范

| 项目 | 规范 |
|---|---|
| 页面外壳 | 208px 左侧导航、64px 顶栏；页面右上角仅保留外观入口 |
| 导航顺序 | 微信消息台 → 系统设置 → AI 设置 → 消息转发 → 诊断 |
| 色彩 | 微信绿用于主操作和选中；浅灰页面背景、白色内容区、深灰文字 |
| 字体 | 中文无衬线；正文 14px，页面标题 24px，说明文字 12–13px |
| 间距 | 内容区边距 32px，区块间距 24px，字段间距 16–20px |
| 控件 | 默认高度 40px；圆角 8–10px，细边框，弱阴影 |
| 主操作 | 每个任务区域一个主按钮；危险操作收进详情，避免与日常操作并列 |
| 状态 | 文字配合颜色；成功、警告、失败颜色不随主题色变化 |

管理页不常驻消息台的微信号选择器，避免误以为全局 AI 设置随账号切换。转发字段和诊断筛选在需要时明确显示账号。

## 1. 系统设置

设计稿：[系统设置](system-settings.png)

采用单页纵向分组，不再增加「设备 / 发现 / 读取」三层切换：设备列表是主要区域，自动发现和历史读取紧随其后。常用信息直接看到，低频跨网段配置折叠。

- 页面主操作为「搜索设备」。搜索过程中同一按钮显示进度并禁用重复点击，结果就地出现。
- 已接入设备统一用表格；每行只保留「查看」。连接详情、重新识别、撤销授权进入详情抽屉，减少横向按钮堆积。
- 发现未接入设备后，在列表下方出现「可连接设备」，各行提供「连接」。仅在开始配对时显示验证码及双方确认状态，完成后移入已接入列表。
- 旧版手动添加是次要文字入口；不与主操作竞争。
- 自动发现、间隔、历史读取作为一组待保存配置。仅有修改时底部出现「放弃修改 / 保存设置」；无修改时只显示「已保存」。图中若保留禁用保存按钮，实施时可直接隐藏。
- 跨网段展开后才显示网段新增、列表和地址预算；不将高级网络参数铺满首屏。

## 2. AI 设置

设计稿：[AI 设置](ai-settings.png)

左侧是模型与角色表单，右侧是名称规则列表；无需模型、角色、规则之间反复切换。窄屏改为上下排列。

- 配置范围写为「全局配置」，不增加全局开关，以免与会话回复模式形成重复控制。
- 接口、模型、密钥、提示词和图片选项连续填写；密钥隐藏，留空保留原值。
- 名称规则显示优先顺序和回复模式，提供「编辑」及更多菜单；不再添加与回复模式重复的启用开关。
- 添加和编辑规则使用同一种轻量抽屉；规则顺序在更多菜单提供上移/下移，避免常驻多个排序按钮。
- 页面所有修改，包括规则修改，统一进入待保存草稿。规则抽屉主按钮称「完成」，只有页面底部「保存设置」提交到服务；不能出现两个含义不清的保存按钮。
- 图中展示有修改状态，保存区清楚说明「未保存的修改」。无需无意义的成功率卡片或尚未支持的连接测试。

## 3. 消息转发

设计稿：[消息转发及规则编辑](message-forwarding.png)

列表与编辑抽屉同屏，来源、条件和目标一次完成填写，不再设计四步向导。

- 页面唯一主操作「添加规则」；规则行保留启用状态、编辑及更多菜单。
- 来源和目标都显示「账号 · 会话」，避免同名群误选。
- 条件选择后显示相应字段；不相关字段隐藏。摘要实时生成，不要求用户再点一次确认摘要。
- 编辑抽屉固定底部「取消 / 保存规则」，无整页保存按钮。每条规则独立提交，成功后关闭抽屉并更新列表。
- 快捷启停也是即时独立提交；提交中禁用开关，失败回滚并在该行提示，不弹出不必要的确认。
- 删除规则放在更多菜单，才显示确认；保存无需二次确认。
- 只有数量足够多时才加入搜索和分页；三条规则不占用额外筛选区域。

## 4. 诊断

设计稿：[诊断](diagnostics.png)

异常优先，诊断是排查工具，不做装饰性仪表盘。去掉重复的概览数字卡，保留直接影响操作的提示。

- 顶部只筛选账号和设备；不提供尚未具备完整历史查询能力的时间筛选。筛选作用于当前已加载数据，实际页面须注明覆盖范围。
- 自动刷新与手动刷新同处一个紧凑区域；读取中禁止重复刷新，刷新不关闭展开详情。
- 任务与异常按「需要关注 / 全部 / AI 任务」组织，同一问题不在多个区块重复列出。整合方式需要适配现有不同数据来源。
- 点击「查看」原位展开任务详情，不另开页面或叠加弹窗；便于持续比较列表上下文。
- 对结果未知的发送任务提示先核对手机，不提供直接重发按钮。对读取不完整说明已保留结果。
- 服务日志默认折叠，用户需要时再展开；不在首页显示大段技术文本。

## 交互删减清单

| 删减 | 保留的最短路径 |
|---|---|
| 系统设置页内额外标签导航 | 同一页分组，高级配置折叠 |
| 设备行多个动作按钮 | 查看 → 设备详情 |
| AI 启用开关与回复模式双重控制 | 单一回复模式 |
| 转发四步向导和额外摘要确认 | 单个编辑抽屉，实时摘要 |
| 转发规则保存与全局保存并存 | 每条规则独立保存 |
| 诊断重复统计卡与异常列表 | 一条重点提示 + 一个任务列表 |
| 同时展开多个浮层 | 子页面仅打开当前任务需要的抽屉 |

## 统一反馈与验收

字段错误在字段旁显示；保存失败保留全部输入。仅在有未保存草稿并主动离开时提示，正常浏览不弹确认。保存成功可用短提示反馈，不弹成功对话框。抽屉支持 Esc 和关闭按钮，有修改时按统一离开规则处理。
